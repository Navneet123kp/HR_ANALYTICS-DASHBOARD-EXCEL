# HR Analytics Dashboard | Microsoft Excel

## 📊 Project Overview

The **HR Analytics Dashboard** is an interactive Excel-based dashboard designed to analyze and visualize key Human Resources (HR) metrics. It helps HR professionals and management understand workforce distribution, employee demographics, salary trends, performance ratings, and recruitment patterns.

The dashboard provides a comprehensive view of HR data through interactive slicers, KPI cards, and dynamic charts, enabling data-driven decision-making.

## 🎯 Project Objectives

- Analyze employee distribution across different departments and cities.
- Monitor total salary expenditure.
- Understand workforce demographics and gender distribution.
- Evaluate employee performance ratings.
- Analyze employee hiring trends over the years.
- Track projects completed by employees.
- Provide management with an interactive HR reporting solution.

## 🚀 How to Use

1. Download the Excel workbook from this repository.
2. Open the workbook in Microsoft Excel 2021 or a compatible version.
3. Navigate to the **Dashboard** worksheet.
4. Use the slicers to filter the data.
5. Explore KPI cards and charts to understand HR performance.
6. Select different combinations of slicers to perform detailed analysis.
